# pmlove3.github.io

Personal website, served via [GitHub Pages](https://pages.github.com/).

Live at: https://pmlove3.github.io

## Local preview

No build step — open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Editing

- [`index.html`](index.html) — page content
- [`style.css`](style.css) — styling

Pushing to the `main` branch deploys automatically.
